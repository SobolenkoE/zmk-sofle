# ZMK Sofle Firmware

Персональная прошивка для сплит-клавиатуры Sofle на базе ZMK.

## Источники

- Оригинальный репозиторий: https://github.com/a741725193/zmk-sofle
- Форк: https://github.com/SobolenkoE/zmk-sofle

## Особенности прошивки

- ZMK (main) — плата оформлена как shield на базе nice_nano_v2
- Дисплеи nice!view на обеих половинах
- Энкодер слева, крестовина (мини-джойстик) справа: движение курсора, нажатие — левый клик
- Авто-выключение подсветки клавиш и подложки при простое
- Настройки питания и сна (сон через 20 минут)
- Кастомные слои и макросы

## Сборка прошивки

Прошивка собирается автоматически в GitHub Actions при каждом пуше
(артефакты `firmware-*.zip` в разделе Actions).

Локальная сборка (требуется west / zmk-dev-container):

\`\`\`bash
west build -b nice_nano_v2 -d build/left -- -DSHIELD="eyelash_sofle_left nice_view" -DZMK_CONFIG="config"
west build -b nice_nano_v2 -d build/right -- -DSHIELD="eyelash_sofle_right nice_view" -DZMK_CONFIG="config"
\`\`\`

Файлы прошивки будут находиться в:
- \`build/left/zephyr/zmk.uf2\` (левая сторона)
- \`build/right/zephyr/zmk.uf2\` (правая сторона)

## Установка прошивки

1. Нажмите на кнопку сброса (reset) на клавиатуре
2. Клавиатура появится как USB-накопитель
3. Скопируйте файл \`zmk.uf2\` на этот диск
4. Клавиатура перезагрузится с новой прошивкой

> После переезда на ZMK main рекомендуется один раз залить
> `settings_reset` (артефакт из CI) на обе половины — это сбросит
> сохранённые в флеше настройки и привязки Bluetooth, а затем
> выполнить сопряжение заново.

## Карты слоёв

Актуальные карты слоёв: \`keymap-drawer/eyelash_sofle.svg\`.

Базовый слой (Layer 0):
- Стандартная раскладка QWERTY
- Крестовина: движение курсора, нажатие — левый клик

Слой 1 (MOVE):
- Функциональные клавиши, управление курсором и клики
- Скролл энкодером

Слой 3 (AJUST):
- Настройки Bluetooth и RGB, переключение USB/BLE
- Функции сброса

## Управление питанием

- **Soft Off**: Q + S + Z (удерживать 2 секунды)
- Выход из Soft Off: нажатие кнопки сброса
- Автоматический переход в спящий режим: 20 минут бездействия
